# GeekStore Dashboard

Painel administrativo com identidade visual em **amarelo e preto**, criado para lojas geek de jogos.

## O que foi adicionado

- Interface principal `dashboard` com destaque para produtos cadastrados.
- Painel rápido com contagem total de produtos.
- Cards de destaque para os produtos mais recentes.
- Navegação direta para `Produtos`, `Categorias`, `Marcas` e `Fornecedores`.
- Tema estilizado com fundo escuro e elementos em amarelo vibrante.

## Como usar

1. Acesse a rota `/dashboard` após autenticar.
2. Confira os produtos em destaque na tela inicial.
3. Use os links para gerenciar `Categorias`, `Marcas`, `Fornecedores` e `Produtos`.

## Observações

- O dashboard agora carrega automaticamente os últimos produtos cadastrados.
- Caso não haja produtos cadastrados, o painel mostra uma mensagem informativa.
- A interface foi criada para manter consistência com a identidade visual da loja geek.
